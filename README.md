# 우리집 퀘스트 보드

갤럭시 탭 거실 대시보드. 아들의 시간대별 게임형 미션(아침 등교 준비, 하교 후 과제·일일공부·책 읽기, 저녁, 잠자리), 코인·레벨·배지 보상, 날씨, 가족 일정, 막내 기록.

- 서버 없이 정적 파일만으로 동작해요. 기록은 태블릿 브라우저(localStorage)에만 저장돼요.
- 날씨: Open-Meteo (API 키 불필요).
- `index.html`은 `src/family-quest.html`에 head(manifest, 서비스워커)를 붙여 만든 파일이에요.
- 탭 크롬에서 열고 메뉴 > "홈 화면에 추가"를 누르면 앱처럼 전체 화면으로 실행돼요.
